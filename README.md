# auto-recon

Automated reconnaissance framework for initial access operations.

## Features
- Subdomain enumeration
- Port scanning integration
- Service fingerprinting
- Network mapping
- Automated reporting

## Usage
```bash
bash recon.sh -t <target> -o <output>
```

## Examples
```bash
bash recon.sh -t 192.168.1.0/24 -o results.txt
bash recon.sh -t target.com -o recon_output.txt
```

## Requirements
- bash
- nmap
- curl
- whois
